A make.fun entry for "The Excuse That Almost Works" — the one line a gamer texts the boss to skip work on GTA 6 launch week.

## The entry

> Sorry boss, wifi's been dead since 6am, router's just blinking red. Provider says Thursday at the earliest, I'm stuck.

118 characters, 19 words, 1 line. The angle: "my internet died" — except the router is fine, the gamer unplugged it himself and is now committed to the lie. The blinking-red router and the Thursday provider slot are the boring, specific details a tired manager would almost believe.

## Run it

```sh
python3 main.py
```

`main.py` (Python stdlib only) verifies the entry against the gate in RULES.txt — UTF-8 text, 1 to 140 characters, not only white space, a single line, at most 20 words — then writes it to `/output/entry.txt`.
